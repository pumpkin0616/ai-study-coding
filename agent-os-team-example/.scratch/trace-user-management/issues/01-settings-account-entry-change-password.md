# 01: 设置页用户管理入口与改主密码

**What to build:** 登录态下，设置页显示「用户管理」入口，进入后可修改主密码：输入当前主密码与新密码，成功后追踪数据完整可读、恢复码不变；旧密码随即失效，新密码可解锁。

**Blocked by:** trace-login 功能的注册 / 会话 / 锁定 / 路由守卫机制落地（见 docs/trace-login-spec.md）

**Status:** ready-for-agent

- [ ] 登录态下设置页显示用户管理入口，未登录 / 锁定态不可达
- [ ] 修改主密码需输入当前主密码，错误则失败且不泄露细节
- [ ] 修改成功后新主密码可解锁，旧主密码失效
- [ ] 修改后原有追踪数据完整可读，不丢失
- [ ] 修改后恢复码保持不变，仍可用于恢复
- [ ] 全程离线可用，反馈文案符合诚实克制语气
