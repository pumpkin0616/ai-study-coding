# 01: 设置页退出登录入口与基础退出路径

**What to build:** 登录状态下，设置页显示「退出登录」入口；点击后立即清除当前会话与内存解锁密钥，跳转回登录页，主数据页重新被路由守卫保护；用户可再次输入主密码登录并看到原数据完好。

**Blocked by:** trace-login 功能的会话 / 锁定 / 路由守卫机制落地（见 docs/trace-login-spec.md）

**Status:** ready-for-agent

- [ ] 登录态下设置页显示「退出登录」，未登录 / 锁定态不显示
- [ ] 点击退出后跳转登录页，主数据页路由被守卫拦截
- [ ] 退出后内存解锁密钥被清除，未重新登录无法读取解密数据
- [ ] 重新输入主密码登录后，原追踪数据完好可读
- [ ] 全程离线可用，退出反馈文案符合诚实克制语气
