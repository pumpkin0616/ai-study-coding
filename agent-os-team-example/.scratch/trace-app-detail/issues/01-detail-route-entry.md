# 01: 详情页入口与路由框架

**What to build:** 首页的 App 行可点击，进入该 App 的独立路由详情页；页面显示 App 名称并可返回首页；数据经本地加密存储读取，无数据时给出克制的空态。详情页在未登录状态下不可达。

**Blocked by:** Trace 首页每日 App 清单与本地加密数据读取能力落地

**Status:** ready-for-agent

- [ ] 点击首页 App 行进入对应 App 的详情页（独立路由，可返回 / 前进 / 直达链接）
- [ ] 详情页正确显示该 App 的名称
- [ ] 数据经本地加密存储读取，离线可用
- [ ] 无数据时显示克制的空态，不报错
- [ ] 未登录访问详情页被路由守卫拦截
